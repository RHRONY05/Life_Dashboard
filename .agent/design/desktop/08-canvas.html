TCP three-way handshake

TCP opens a connection with three segments, so both sides agree on their starting sequence numbers before any data flows:

  1. SYN: the client picks an initial sequence number x and sends it.
  2. SYN-ACK: the server picks its own number y and acknowledges x + 1.
  3. ACK: the client acknowledges y + 1. The connection is open.
