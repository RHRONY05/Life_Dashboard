## 1. What is Live in Production

- **Production URLs:** [https://life-rony.vercel.app](https://life-rony.vercel.app) & [https://dashboard.rhrony05.me](https://dashboard.rhrony05.me)
- **Shared Supabase Database & Storage:**
  - Database: Table `public.notes` created with RLS (`"own notes"` policy).
  - Storage: Private bucket `life-notes` created with 1MB file limit, restricted image mime types (`image/webp`, `image/png`, `image/jpeg`, `image/gif`), and folder isolation (`storage.foldername(name)[1] = auth.uid()`).
  - Strict preservation: All Vocab tables (`words`, `quiz_attempts`) remain 100% untouched.
- **Pages & Features:**
  - **/canvas:**
    - **Scratch (Local copy-paste page):**
      - Full TipTap v3 rich-text editor with Swiss Ink styling (`prose`, headings H1–H3, checklists, bullet/numbered lists, quotes, code blocks with syntax badge, GFM tables, links, images).
      - **Zero server leakage:** Scratch content lives in browser IndexedDB (`idb`) only. Never transmitted across the network.
      - **Single-tab ownership:** Managed via Web Locks (`life-scratch`) and `BroadcastChannel`. Opening in a second tab displays a read-only banner with a **Use here** button to steal ownership safely.
      - **Smart paste:** Strips inline styles, foreign classes, scripts, and comments; converts VS Code clipboard data into code blocks; parses markdown or URLs; shrinks pasted images client-side to WebP ≤1MB (`max 1600px`).
      - **Copy as Markdown (`Ctrl+Alt+M`):** Serializes document to clean GFM Markdown with toast count.
      - **Clear Scratch:** Clears document with 10-second Undo toast. Unreferenced images cleaned from IndexedDB.
    - **Saved Notes:**
      - **"Save as note" (`Ctrl+S`):** Saves Scratch content as a named note (`titleFromText`), uploads local `idb:` images to private Supabase storage (`life-notes`), and places the new note at the top of the notes list while keeping Scratch open and unchanged.
      - **Notes Pane:** Left sidebar with search input (200ms debounce), notes count (`Notes · N`), relative timestamps ("just now", "10m ago", "yesterday"), and `"via <agent>"` badge for agent-created notes.
      - **Note Editor:** Editable title in the header (saved on blur/Enter, falls back to previous title if empty), autosave with 800ms debounce, and `beforeunload` warning when changes are pending.
      - **Stale Concurrency Protection:** Optimistic concurrency via `baseUpdatedAt`. If modified in another tab, displays a 409 conflict banner with **Load latest** and **Keep mine** options.
      - **Images in Notes:** Images upload to `/api/notes/[id]/images` (verified with magic bytes: PNG, JPEG, WebP, GIF; ≤1MB limit; ≤30 images per note). Rendered securely via `/api/notes/images/<path>` with 10-minute signed URLs.
      - **Copy to Scratch & Delete Note:** Dropdown menu `⋯` allows copying note contents into Scratch or deleting the note (with confirmation dialog and automatic storage cleanup).
      - **Desktop & Mobile Parity:** Full desktop layout (280px sidebar + centered editor) and mobile layout (Segmented "Scratch · Notes", full-width note view with back button, sideways scrolling sticky toolbar).

### How to Use It in 4 Lines:
1. Navigate to **/canvas** (or press `g` then `c`).
2. Paste anything into **Scratch** (AI chats, screenshots, terminal output, links) — it stays securely in this browser even if you reload or close the tab.
3. Click **Save as note** (or press `Ctrl+S`) to permanently archive it into your private cloud notes.
4. Search notes in the sidebar, open any note to edit with seamless 800ms autosave, or click `Ctrl+Alt+M` to copy clean Markdown ready to share.

## 3. Code-Flow Walkthrough: Saving Scratch as a Note

Here is how saving Scratch as a persistent cloud note flows end to end:

```
[Browser UI: CanvasEditor.tsx]
   │ User clicks "Save as note" or presses Ctrl+S
   ▼
[Canvas Client Execution]
   │ 1. Serializes TipTap JSON doc to Markdown via `docToMarkdown(json)` (src/lib/canvas/markdown.ts).
   │ 2. Extracts title via `titleFromText(md, new Date())` (src/lib/domain/canvas.ts).
   │ 3. Issues initial creation request:
   ▼
[POST /api/notes (src/app/api/notes/route.ts)]
   │ 4. `requireOwner()` verifies authenticated session.
   │ 5. Validates payload using `CreateNoteSchema` (src/lib/schemas.ts).
   │ 6. `createNote()` (src/lib/services/notes.ts):
   │    - Enforces 300 notes maximum check.
   │    - Inserts row into `public.notes` with user_id, title, doc, body_md, created_by='owner'.
   │    - Returns created NoteDto (status 201).
   ▼
[Image Storage Sync in Browser]
   │ 7. Scans document for local images (`idb:<uuid>`).
   │ 8. For each image: reads Blob from IndexedDB, uploads via `POST /api/notes/[id]/images`.
   │ 9. Service validates image magic bytes (PNG/JPEG/WebP/GIF), verifies ≤1MB limit and ≤30 images cap.
   │ 10. Stores in `life-notes` bucket at `<userId>/<noteId>/<uuid>.<ext>`.
   │ 11. Returns reference `sb:<path>`.
   │ 12. Browser updates TipTap doc with `sb:` references and calls `PATCH /api/notes/[id]` with `baseUpdatedAt`.
   ▼
[Browser UI: Feedback & List Update]
   │ 13. Re-fetches notes list (`GET /api/notes`) so the new note appears at the top.
   │ 14. Displays toast: `Saved as “<title>”` with an "Open" action button.
   │ 15. Scratch editor remains intact and completely unchanged.
```

## 4. Open Human Steps & Decisions Made

### Open Human Steps:
- None blocking M3.

### Decisions Made:
- **Client-Only Canvas Component:** Encapsulated TipTap v3 and IndexedDB operations in a dedicated `"use client"` component (`CanvasClient.tsx`) with `ssr: false` dynamic import to comply with Next.js 16 Server Component boundary restrictions.
- **Robust Web Lock Acquisition:** Added retry logic and module-level lock release management to handle React 19 StrictMode fast-mount cycles cleanly across multiple tabs.
- **Image Architecture:** Local Scratch images remain in client-side IndexedDB (`idb:`). Cloud note images use private Supabase storage (`sb:`), served through a cached redirect endpoint (`/api/notes/images/[...path]`) generating 10-minute signed URLs.
