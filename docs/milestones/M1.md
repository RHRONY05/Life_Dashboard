## 3. Code-Flow Walkthrough: Ticking a Task on Today

Here is how a task tick flows from user interaction in the browser down to the database and back:

```
[Browser UI: TaskRow.tsx]
   │ User clicks <Checkbox checked={task.done} />
   ▼
[TodayBoard.tsx]
   │ 1. Optimistic Update: Immediately toggles `task.done = !task.done` in React state,
   │    moves task to bottom of column, and triggers a toast with "Marked done / Undo".
   │ 2. Issues HTTP request:
   ▼
[PATCH /api/tasks/[id] (src/app/api/tasks/[id]/route.ts)]
   │ 3. `requireOwner()` (src/lib/auth.ts):
   │    - Inspects Supabase auth session cookie.
   │    - Verifies user exists and email === ALLOWED_EMAIL (muhammadrony147@gmail.com).
   │    - Returns authenticated Owner `Ctx` containing user-scoped Supabase client.
   │ 4. `UpdateTaskSchema.parse(body)` (src/lib/schemas.ts):
   │    - Validates `{ done: boolean }`.
   ▼
[tasks service: updateTask() (src/lib/services/tasks.ts)]
   │ 5. Executes SQL via Supabase RLS:
   │    `UPDATE tasks SET done = :done, done_at = now() WHERE id = :id AND user_id = :userId`
   │ 6. If marking done, increments `position` to move it below open tasks.
   │ 7. Returns updated TaskDto.
   ▼
[Browser UI: Response Handler in TodayBoard.tsx]
   │ 8. Confirms success (or rolls back optimistic state with error toast if request failed).
```
