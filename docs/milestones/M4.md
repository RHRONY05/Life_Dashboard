## 1. What is Live in Production

- **Production URLs:** [https://life-rony.vercel.app](https://life-rony.vercel.app) & [https://life.rhrony05.me](https://life.rhrony05.me)
- **Database & Tables:**
  - `public.renewals`: Stores subscriptions, hosting, domains, free credits, with currency (`BDT` or `USD`), cycle (`monthly`, `yearly`, `once`), next renewal date, status (`active`, `paused`, `ended`), and cancellation reminders.
  - `public.reminder_log`: Stores sent reminder stages (`7d`, `1d`, `0d`, `-1d`, `20d`) with unique constraint `(renewal_id, renews_on, stage)` guaranteeing idempotent notification dispatch.
  - `public.api_keys`: Hashed API keys (`key_hash` using SHA-256), prefix (`ld_live_...`), scopes array, last used timestamp, created/revoked timestamps. Raw secrets are single-exposure and never stored.
  - `public.audit_log`: Audit trail for agent tool invocations with tool name, execution time, result code (`ok`, `denied`, `error`, `rl`), sanitised arguments, summary, and duration.
  - `public.quick_links`: Up to 12 quick links ordered by position with title, URL, and icon.
- **Pages & Features:**
  - **/renewals (V6):**
    - **Overview & Totals:** Automatic monthly normalisation totals per currency (e.g. `≈ ৳1,450 / month · $21.00 / month`).
    - **Smart Groups:** Active, Paused, and Ended renewal buckets.
    - **Overdue Banner:** Noticeable alert for overdue renewals with one-click resolution.
    - **Renewed & Undo Action:** "Renewed" button advances the next renewal date cleanly to the next cycle with a 10s undo toast.
    - **Nav Badge:** Header navigation count for items needing attention.
    - **Today Rail Block:** "Coming up" block surfacing renewals due within 30 days right beside tasks.
  - **/api/cron/daily (V6):**
    - Secure cron endpoint requiring `Authorization: Bearer <CRON_SECRET>`.
    - Daily reminder digest sent to Rony's Gmail via nodemailer SMTP at $d = 7, 1, 0, -1, 20$.
    - Idempotent execution (multiple runs on the same day never duplicate emails).
    - Automatic retention cleanup deleting audit rows older than 90 days.
  - **/settings (V7):**
    - **Anchor Navigation:** Swiss Ink sidebar navigating `#agents`, `#activity`, `#links`, `#email`.
    - **Endpoint Copy:** One-click copy for the MCP endpoint (`https://life.rhrony05.me/api/mcp`).
    - **API Keys (`#agents`):**
      - Full key management with module scope chips (`tasks rw`, `money r`), relative last used times, and single-exposure secret reveal.
      - Presets for Muse, Antigravity, and Claude Code.
      - Ready-to-copy client configuration snippets for Antigravity, Claude Code, and HTTP headers.
      - Confirmation modal before closing to prevent losing the unhashed secret.
      - Revocation greys out the key and moves it below active keys.
    - **Activity Log (`#activity`):**
      - Full audit trail showing timestamp, agent name, tool summary, result badge (`ok`, `denied`, `error`, `rl`), and execution duration in ms.
      - Agent filter dropdown and cursor-based "Load more" pagination.
    - **Quick Links (`#links`):**
      - Create, edit, and delete up to 12 quick links with 10 visual icons.
      - Live sync with the Today board grid (`LinkGrid`) and mobile strip (`LinkStrip`).
    - **Email Test (`#email`):**
      - Send test email button with instant status feedback and inline error handling.

### How to Use It in 4 Lines:
1. Go to **/renewals**: Add subscriptions, domains, and credits with renewal dates to get automatic monthly spend totals in BDT and USD.
2. Go to **/settings** -> **Agents**: Create scoped API keys for Muse, Antigravity, or Claude Code, and copy ready-to-paste MCP configuration snippets.
3. Switch to **Quick links**: Add your daily sites (Vocab, GitHub, Portfolio) with custom icons to have them right on your Today rail and mobile board.
4. Go to **Email reminders**: Trigger a test email to verify your Gmail SMTP digest arrives in your inbox.
